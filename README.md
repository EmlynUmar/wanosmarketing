# # WanosMarketing Growth Platform

![WanosMarketing Logo](./public/logo.png)

A modern, conversion-focused marketing platform built for **WanosMarketing** — a digital growth agency helping brands scale online through performance advertising, customer acquisition systems, automation, and website optimization.

The platform combines a premium marketing website with a custom admin dashboard that allows WanosMarketing to manage content, showcase results, update statistics, and monitor business growth metrics.

---

# 🚀 Project Overview

WanosMarketing helps businesses grow through:

- Paid Advertising (Meta Ads, TikTok Ads)
- Email Marketing
- SMS Marketing
- Website Optimization
- Conversion-Focused Digital Experiences

This platform is designed to act as a digital sales engine that:

- Builds authority and trust
- Showcases real client results
- Displays successful case studies
- Highlights client testimonials
- Shows brands they have worked with
- Converts visitors into booked strategy calls

# ⚙️ Installation & Setup

Clone repository:

```bash
git clone https://github.com/YOUR_USERNAME/Wanosmarketing.git
```

Navigate into project:

```bash
cd Wanosmarketing
```

Install dependencies:

```bash
npm install
```

Create environment file:

```
.env.local
```

Add required variables:

```env
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=

NEXT_PUBLIC_CALENDLY_URL=
```

Run development server:

```bash
npm run dev
```

Open:

```
http://localhost:3000
```
